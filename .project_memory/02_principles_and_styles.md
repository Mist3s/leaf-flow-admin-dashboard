# Принципы и стили

## Стилизация и UI
- В качестве UI-фреймворка используется **Material-UI (MUI) v5**.
- Компоненты стилизуются двумя основными механизмами:
  1. `sx` проп MUI для быстрых инлайн-стилей и применения токенов темы прямо в JSX.
  2. `styled` API от MUI (`@mui/material/styles`) для создания обособленных, семантических стилизованных компонентов (например, `StyledTableContainer`, `MobileCard`, `SearchBar`).
- Приложение поддерживает темизацию через обертку `ThemeProviderWrapper`, тема настраивается централизованно (по умолчанию `PureLightTheme`) и сохраняется в `localStorage`.

## Подход к разработке пользовательского интерфейса
- **Адаптивность (Responsive Design):** Широко используется хук `useMediaQuery` и брейкпоинты темы (например, `theme.breakpoints.down('md')`).
- **Mobile First / Деградация представлений:** Для мобильных экранов компоненты могут иметь совершенно другой вид. Например, для табличных данных на мобильных устройствах рендерятся списки карточек (`MobileCard`), тогда как на десктопе — полноформатные таблицы (`Table` из MUI).
- **Переиспользование и инкапсуляция:** Сложная логика отображения, пагинация и фильтры выносятся в мощные обобщенные компоненты (прекрасный пример: `src/components/DataTable`), которые параметризуются извне (`columns`, `data` и кастомные рендеры).

## Стандарты написания кода
- **Язык:** TypeScript. Строгая типизация интерфейсов для данных и Props (`interface DataTableProps<T>`, использование дженериков - Generic Components).
- **Компоненты:** Исключительно функциональные React-компоненты с использованием встроенных и пользовательских хуков.
- **Код-стайл:** Поддерживается `Prettier`, а строгие синтаксические и архитектурные правила кода обеспечиваются `ESLint` (воздействуя на базе `airbnb-typescript`).
