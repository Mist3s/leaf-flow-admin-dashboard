# Память проекта
Этот каталог содержит актуальную информацию о проекте, его архитектуре, стандартах и конфигурации.

## Содержание
1. [Обзор проекта](00_overview.md) - основная информация о проекте, стек технологий, структура папок.
2. [Архитектура](01_architecture.md) - описание архитектурных паттернов, роутинга, работы с API и состоянием.
3. [Принципы и стили](02_principles_and_styles.md) - стандарты написания кода, стилизация, использование MUI.

## Правила работы с памятью
- Перед выполнением любой задачи необходимо изучить `index.md` и релевантные разделы.
- При обнаружении несоответствия между памятью и кодом/конфигами, код считается источником истины, а файлы памяти должны быть обновлены.
- Все изменения в файлах памяти должны сопровождаться датой изменения.
