# Обзор проекта

## 🍃 Leaf Flow Admin Dashboard
Административная панель для управления чайным магазином Leaf Flow.

### Основной стек технологий
- **Framework:** React 17.0.2
- **Language:** TypeScript 4.7.3
- **UI Library:** Material-UI (MUI) 5.8.2
- **Routing:** React Router 6.3.0
- **HTTP Client:** Axios 1.13.4
- **State Management (Server):** React Query 3.39.3
- **Date Utility:** date-fns 2.28.0
- **Charts:** ApexCharts 3.35.3

### Основные возможности
- Управление товарами (создание, варианты, изображения), заказами, пользователями, категориями, отзывами.
- Глобальный поиск, адаптивный мобильный интерфейс.

### Инфраструктура
- Шаблон: Базируется на Tokyo Free White React Admin Dashboard.
- Сборка: Create React App (react-scripts).
- Линтинг/форматирование: ESLint + Prettier.
